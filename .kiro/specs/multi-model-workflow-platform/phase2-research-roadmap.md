## 一、战略定位

### 当前生态位
**细分补充者** —— 面向国内开发者和中小企业的"国产大模型可视化编排工具"

### 长期愿景
**"国产AI能力的乐高积木"** —— 像搭乐高一样，把国产大模型、图像生成、语音识别等AI能力拼装成你想要的应用

### 核心竞争维度
1. 上手速度（注册到跑通第一个工作流 < 10分钟）
2. 国产模型覆盖度
3. 火山引擎生态深度绑定

## 二、差异化分析

### 最脆弱的差异点（易被复制）
- "支持7种国产模型"这个数字本身
- 中文界面翻译
- 基础的用量统计功能

### 最坚硬的护城河（难以复制）
1. **火山引擎生态深度绑定** —— 即梦AI是独家能力，Dify不愿做、Coze做了会"资敌"
2. **工作流资产沉淀** —— 用户创建的工作流、模板形成迁移成本
3. **垂直场景的极致体验** —— 在特定场景做到"最好用"

### 竞品不愿做的场景（生存缝隙）
| 场景 | 原因 | 机会 |
|------|------|------|
| 讯飞星火语音转写+LLM联动 | 讯飞是字节竞争对手 | 成为"星火生态最佳搭档" |
| 火山引擎即梦AI图像生成 | 字节系能力，Dify不会主动接入 | 深耕"火山引擎全家桶" |
| 私有化部署+国产信创适配 | 大厂SaaS优先 | 政企市场敲门砖 |
| 小众模型抢先支持 | 大厂只接主流模型 | 成为新模型"首发平台" |

export async function loadBuiltinTemplates() {
  const templatesDir = path.join(__dirname, '../templates');
  const files = fs.readdirSync(templatesDir).filter(f => f.endsWith('.json'));
  
  for (const file of files) {
    const template = JSON.parse(fs.readFileSync(path.join(templatesDir, file)));
    
    // 检查是否已存在
    const existing = await templateRepo.findOne({ 
      where: { name: template.name, isBuiltin: true } 
    });
    
    if (!existing) {
      await templateRepo.save({
        ...template,
        createdAt: new Date(),
        usageCount: 0,
      });
    }
  }
}

async checkAndAwardBadges(userId: string) {
  const user = await userRepo.findOne(userId);
  const newBadges = [];
  
  if (user.templatesCreated >= 1 && !user.badges.includes('newcomer')) {
    newBadges.push('newcomer');

    newBadges.push('star');

## 十九、资源陷阱警示

### 常见资源陷阱

| 陷阱 | 表现 | 为什么是陷阱 | 正确做法 |
|------|------|-------------|---------|
| **UI完美主义** | 反复调整按钮颜色、间距、动画 | 用户不会因为按钮好看而留下 | 先保证功能可用 |
| **功能堆砌** | 不断添加新节点类型、新模型 | 用户用不到的功能是负担 | 先让现有功能好用 |
| **边缘场景** | 处理各种极端情况 | 80%用户不会遇到 | 先覆盖主流场景 |
| **技术炫技** | 引入复杂架构、新技术栈 | 增加维护成本 | 用最简单方案解决 |

### 具体资源陷阱识别

| 陷阱 | 具体表现 | 时间浪费 | 建议 |
|------|---------|---------|------|
| 新增更多模型 | "应该支持百度文心、阿里通义..." | 2-3周 | 暂停，先让现有7个模型稳定 |
| 管理后台完善 | "管理员需要更多统计图表..." | 1-2周 | 够用就行，用户不是管理员 |
| 高级工作流功能 | "需要条件分支、循环..." | 2-3周 | 先验证基础功能有人用 |
| 多语言支持 | "应该支持英文界面..." | 1周 | 先服务好中文用户 |
| 移动端适配 | "用户可能在手机上用..." | 2周 | 工作流编辑不适合手机 |

## 二十三、价值验证核心指标

### 种子用户试验设计（2周）

**最关键的单一观测指标：「首次工作流成功执行率」**

定义：新用户注册后48小时内，成功创建并执行一个完整工作流（含至少1个LLM节点，执行无报错）的比例。

**目标基线**：≥ 50%（低于30%说明产品存在严重上手障碍）

### 用户留存钩子分析

| 候选功能 | 留存潜力 | 分析 |
|---------|---------|------|
| 工作流编辑器 | 中 | 核心功能，但用户不会"为了编辑而编辑" |
| 模板市场 | 中 | 降低门槛，但用完即走 |
| **Token用量统计** | **高** | 形成"数据资产"，用户会回来查看消耗趋势 |
| 多模型切换 | 低 | 一次性决策，不产生回访动机 |

**结论**：Token用量统计是隐性留存钩子，建议强化周报/月报推送、模型成本对比、用量预警功能。

### 增长杠杆分析

**结论**：「模板分享」是当前最具病毒传播潜力的功能

| 功能 | 病毒系数潜力 | 当前状态 |

```typescript
// packages/server/src/services/template-share/sanitizer.ts
export function sanitizeFlowData(flowData: any): any {
    const sanitized = JSON.parse(JSON.stringify(flowData));
    
    for (const node of sanitized.nodes || []) {
        const nodeData = node.data || {};
        
        // 1. 移除凭证引用
        if (nodeData.credential) {
            nodeData.credential = null;
            nodeData.credentialRequired = true;
        }
        
        // 2. 移除敏感输入字段
        const sensitiveFields = ['apiKey', 'secretKey', 'accessToken', 'password'];
        for (const field of sensitiveFields) {
            if (nodeData.inputs?.[field]) {
                nodeData.inputs[field] = '';
            }
        }
    }
    
    return sanitized;
}
```

## 二十六、成功仪表盘

### 核心增长指标

**定义**：每周由用户生成的模板被克隆使用的总次数（UGC Clone Count）

这个指标比"模板总数"更能证明生态活力，因为它衡量的是"模板的实际价值"而非"数量堆积"。

### 实时监控指标（TOP 5）

| 指标 | 定义 | 健康阈值 |
|------|------|---------|
| 每日分享链接生成数 | 用户点击分享并生成链接的次数 | ≥ 3/天 |
| 链接点击→注册转化率 | 访客点击分享链接后注册的比例 | ≥ 15% |
| 注册→克隆转化率 | 新注册用户克隆模板的比例 | ≥ 40% |
| TOP 10模板周使用量 | 最热门10个模板的周克隆总数 | ≥ 50次 |
| UGC模板占比 | 用户创建模板 / 总模板数 | ≥ 60% |

### 熔断机制

**熔断阈值**：计划推进2周后，如果出现以下任一情况，立即调整策略：

| 信号 | 阈值 | 应对措施 |
|------|------|---------|
| 每周新增UGC模板数 | < 2个 | 加强创作者激励，降低发布门槛 |
| 分享链接点击率 | < 5% | 优化分享文案和预览页 |
| 克隆后7日留存 | < 10% | 检查模板质量和新手引导 |
