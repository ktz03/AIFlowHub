# 代码简化器 (Code Simplifier)

当用户说 "简化代码" 或 "@code-simplifier" 时，执行以下优化：

## 简化原则

### 1. 删除死代码
- 未使用的变量
- 未调用的函数
- 注释掉的代码块
- 无用的 import 语句

### 2. 合并重复逻辑
- 提取公共函数
- 使用高阶函数替代重复循环
- 合并相似的条件判断

### 3. 简化条件语句
```typescript
// 之前
if (condition) {
  return true;
} else {
  return false;
}

// 之后
return condition;
```

### 4. 使用现代语法
- 箭头函数
- 解构赋值
- 可选链 (?.)
- 空值合并 (??)
- 模板字符串

### 5. 减少嵌套
- 提前返回 (early return)
- 使用 guard clauses
- 扁平化 Promise 链

## 执行流程

1. 分析当前文件或指定文件
2. 识别可简化的代码模式
3. 生成简化建议列表
4. 询问用户确认后执行修改
5. 运行测试确保功能不变

## 输出格式

```
🔧 代码简化报告
================
文件: xxx.ts

发现 X 处可简化:
1. [行号] 删除未使用变量 `unusedVar`
2. [行号] 合并重复的 if 语句
3. [行号] 使用可选链简化空值检查

是否执行简化? (y/n)
```

## 安全检查

- 不修改公共 API 签名
- 保留必要的类型注解
- 确保测试仍然通过
